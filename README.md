# プライバシーポリシー

合同会社エクセル開発（以下、「当方」といいます）は、提供するスマートフォン用アプリケーション（以下、「本アプリ」といいます）における、ユーザーの情報の取扱いについて、以下のとおりプライバシーポリシー（以下、「本ポリシー」といいます）を定めます。

1. 収集する情報および利用目的
当方が、本アプリを通じてユーザーの氏名、住所、メールアドレスなどの個人を直接特定できる情報を収集・保管することはありません。
ただし、本アプリでは無料でのサービス提供を維持するため、第三者の広告配信サービスを利用しており、広告配信の最適化や成果測定を目的として、以下の非個人情報が自動的に取得される場合があります。
取得される情報の例: デバイスの広告ID（iOSのIDFA、AndroidのAAID等）、OSバージョン、IPアドレス、アプリの利用状況（クラッシュログ等）
利用目的: パーソナライズされた適切な広告の表示、およびトラフィックの分析のため

2. 外部ツール（サードパーティ）の利用について
本アプリでは、広告配信を目的として Google LLC が提供する「Google AdMob」を利用しています。Google AdMobによって収集された情報は、Googleのプライバシーポリシーに基づいて管理されます。Googleによる情報の取扱い、およびデータの使用方法については以下のリンクをご参照ください。

Google ポリシーと規約（Google のサービスを使用するサイトやアプリから収集した情報の Google による使用）
https://policies.google.com/technologies/partner-sites

Google プライバシーポリシー
https://policies.google.com/privacy

3. パーソナライズ広告のオプトアウト（無効化）について
ユーザーは、お使いの端末の設定を変更することで、広告IDを利用したパーソナライズ広告（ターゲティング広告）の配信を制限または無効にすることができます。設定方法は各OSの提供元の案内に従ってください。

iOSの場合: 「設定」>「プライバシーとセキュリティ」>「トラッキング」

Androidの場合: 「設定」>「Google」>「広告」>「広告IDを削除」または「広告のカスタマイズをオプトアウト」

本アプリの利用により生じたトラブルや損害等について、当方は一切の責任を負いかねます。また、本アプリ内に表示される広告から遷移した先の外部サイトやサービスにおける個人情報の取扱い等についても、当方は責任を負うものではありません。

5. プライバシーポリシーの変更について
当方は、法令の変更やサービスのアップデート等に伴い、ユーザーに事前の通知をすることなく本ポリシーの内容を変更することがあります。変更後のプライバシーポリシーは、本ページ（またはアプリ内の指定画面）に掲載された時点から効力を生じるものとします。
